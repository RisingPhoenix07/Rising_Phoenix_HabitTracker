## 🚀 About Rising Phoenix

**Rising Phoenix** is a full-stack personal productivity dashboard built to replace traditional spreadsheet habit systems with a modern, automated web application. It combines customizable habit checklists, streak tracking, weekly progress analytics, and daily reflections into a unified dark-mode workspace.

### ✨ Key Features
- 🏠 **Home Dashboard:** Tracks current streak, weekly completion velocity, daily scores, and dynamic motivational quotes.
- ✅ **Dynamic Daily Checklist:** Real-time completion checkboxes organized by customizable categories/segments with reflection comments.
- 📈 **Weekly Progress Analytics:** Interactive trend line charts and score distributions powered by Recharts.
- ⚙️ **Configurable Segments & Tasks:** Modify, add, or reorder habit categories and tasks without wiping completion history.
- ☁️ **Cloud Database:** Integrated with **Prisma ORM** and **Neon PostgreSQL** serverless hosting.
- 🚀 **Serverless Deployment:** Deployed continuously on **Vercel** with auto-building Prisma engines.
